Snowy's Client (Fabric 26.1.2, client-side, read-only)

Open it in game with:   /paydash
Other commands:         /paydash reset   (new session)      /paydash clear   (wipe all history)

It only READS payment lines from your own chat ("Name paid you $X", "You paid Name $X").
It never sends chat, commands or packets, and never automates anything.
